# Nordlicht Reisen

Responsive Website für das fiktive Reisebüro „Nordlicht Reisen“ – Projektarbeit HTML5 & CSS3 (Fachinformatiker, 2. Lehrjahr).

- 4 Seiten: `index.html`, `reisen.html`, `ueber-uns.html`, `kontakt.html`
- Mobile First mit Media Queries (Smartphone, Tablet ab 768 px, Desktop ab 1024 px)
- Alle Grafiken als 2D-Pixel-Art (SVG), Schrift „Pixelify Sans“
- Bonus: „Fjord-Fahrt“ – Pixel-Spiel im Hero (JavaScript) mit 5 Routen und den Modi Entdecken, Waljagd und Seeschlacht

Öffnen: `index.html` im Browser starten.
